Chemprop is installed in this environment (the `chemprop` command and the Python package), and a checkout of the chemprop repository is in `./chemprop`. Data files are in `./data`. There is no internet access. Keep each training run to at most 30 epochs.

Train a solubility (`logS`) model on `data/solubility_train.csv` and predict `logS` for the molecules in `data/stereoisomers.csv`, saving `predictions.csv` with the columns `smiles` and `logS`, one row per input molecule in the same order. In this problem solubility does not depend on stereochemistry, so stereoisomers of the same molecule must get exactly the same prediction. Use the Chemprop Python API (not the command-line tool) in a script named `train.py`, run it, and save the trained model with `chemprop.models.save_model` to `model.pt`.
