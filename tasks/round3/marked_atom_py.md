Chemprop is installed in this environment (the `chemprop` command and the Python package), and a checkout of the chemprop repository is in `./chemprop`. Data files are in `./data`. There is no internet access. Keep each training run to at most 30 epochs.

In `data/marked_atoms_train.csv`, every SMILES marks one atom with atom-map number 1 (for example `[cH:1]`). Train a model that predicts, for every atom, 1 if it is the marked atom and 0 otherwise. The model must learn which atom is marked only from one extra bond feature: 1 for bonds that touch the marked atom, 0 for all other bonds. Do not give it the mark in any other way (no extra atom features or descriptors), use the default atom and bond featurization otherwise, and pass the bond feature to the model as raw 0/1 values, without rescaling. Predict the molecules in `data/marked_atoms_test_inputs.csv` and save `predictions.csv` with the columns `smiles` and `is_marked` (a list with one value per atom, in the order the atoms appear in the SMILES), one row per input molecule in the same order. Use the Chemprop Python API (not the command-line tool) in a script named `train.py`, run it, and save the trained model with `chemprop.models.save_model` to `model.pt`.
