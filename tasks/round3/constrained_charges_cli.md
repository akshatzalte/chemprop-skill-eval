Chemprop is installed in this environment (the `chemprop` command and the Python package), and a checkout of the chemprop repository is in `./chemprop`. Data files are in `./data`. There is no internet access. Keep each training run to at most 30 epochs.

`data/partial_charges_train.csv` has per-atom partial charges for each molecule (column `charges`: a list with one value per atom, in the order the atoms appear in the SMILES). Train a model that predicts per-atom partial charges such that the predicted charges of each molecule add up exactly to the sum given for that molecule in the column `charge_sum` of `data/partial_charges_train_constraints.csv` and `data/partial_charges_test_constraints.csv` (same row order as the corresponding data files). Predict the charges for the molecules in `data/partial_charges_test_inputs.csv` and save `predictions.csv` with the columns `smiles` and `charges` (a list per molecule, in the same format as the training data), one row per input molecule in the same order. Use the `chemprop` command-line tool, and save the commands you run in `run.sh`.
